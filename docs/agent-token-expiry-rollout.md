# Agent token expiry rollout (draft)

New Relaycast `at_live_*` credentials issued at registration, node registration, recovery, takeover, and self-rotation receive a 15-minute expiry. The server checks the stored deadline on every authenticated REST request. The 60-second previous-token grace slot ends at the earlier of its grace deadline and the old token's expiry. The one-hour policy cap is enforced by the issuance helper; no endpoint accepts a client-selected lifetime.

The `0072_agent_token_expiry.sql` migration leaves `token_expires_at` null for existing credentials. Null is a temporary compatibility state, not a compliant final state. Do not deploy the issuance change until every active client can rotate before expiry and store the replacement securely. After that, audit legacy null rows, migrate or revoke them through the separate rotation lane, and remove null acceptance in a later reviewed change. This draft does not read or rotate production credentials.

A 15-minute expiry alone does not bind a token to a Cloud flow run. Before using these credentials for flows, the Cloud and broker integration must issue authority for the exact run and revoke its Relaycast agent identity at terminal callback or cancellation. A static workspace key must not be delivered to the flow sandbox. A run's agent token may remain in a shared-UID sandbox because agents in that same flow share trust under Khaliq's recorded exception; another flow must never use that sandbox's token.

Staging acceptance checks: rotate before expiry and verify the next REST request uses the replacement; reject the previous token at its original expiry even when grace remains; reject an expired current token and its self-rotation request; verify legacy null rows stay usable during the migration window. Exercise concurrent rotations and peak workspace agent counts against the rotation endpoint's rate limit, since a 15-minute lifetime raises steady rotation traffic. Revoke a synthetic run's agent token and measure server authorization from revoke acknowledgment to last successful request, requiring no more than 60 seconds. Check node/observer WebSocket authority separately: agent tokens cannot open the Relaycast workspace WebSocket, and an agent-token expiry does not itself expire a node token or an existing node connection. Hold deployment until the Cloud run-end path and broker/SDK rotation behavior are reviewed.
